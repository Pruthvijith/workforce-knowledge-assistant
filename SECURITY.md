# Security policy

This is a public educational portfolio implementation with synthetic data. Do not submit production credentials, payment information, customer logs or non-public employer data. Report vulnerabilities privately to the repository maintainer through GitHub security advisories if enabled.

**Before real deployment:** implement workload identity, scoped access control, secrets management, TLS termination, dependency and container vulnerability scanning, signed artifacts, audit logging, retention policies and a reviewed incident response procedure. These controls are not supplied by this reference system.

No security or GDPR compliance certification is claimed.
